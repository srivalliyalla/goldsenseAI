# GoldSense AI

Global Gold Intelligence, Forecasting & Conversational Analytics Platform

## Overview

GoldSense AI is an AI-powered platform that combines:

- Real-time gold market data
- Global currency conversion
- Macroeconomic indicators
- Market and technical factors
- Financial news and sentiment
- Machine learning based forecasting
- LLM-powered conversational analytics
- RAG
- AI agents
- MCP
- Real-time streaming using SSE

The platform analyzes historical and current market information
to provide gold-price insights and model-based forecasts.

## Goals

1. Track global gold prices
2. Convert gold prices into different currencies
3. Analyze factors influencing gold prices
4. Generate next-day forecasts
5. Provide AI-powered explanations
6. Allow users to ask questions using natural language
7. Provide evidence-backed answers using RAG
8. Use AI agents for specialized analysis
9. Expose domain capabilities through MCP
10. Demonstrate scalable production architecture
